# Die Skills in Domis Büro

Angelegt am 22.11.2026 aus Chris' Projekten, angepasst auf die Agentur. Aufrufen mit `/name`. Ein Skill ist ein Ablauf, den Claude vor der Arbeit lädt, damit Gelerntes nicht verloren geht.

| Skill | Wofür |
|---|---|
| `morgen` | Beim Start: Stand, offene Anfragen, To-dos, ein erster Schritt, eine Frage. Eine Erinnerung meldet sich bei «Guten Morgen» oder nach acht Stunden Pause. |
| `lernen` | Am Ende jedes Gesprächs und nach jeder Korrektur: Gelerntes festhalten, Stand sichern. Eine Erinnerung meldet sich bei «merken» und «Gute Nacht». |
| `anfangen` | Vor allem Neuen: neues Werkzeug, neuer Ablauf, neue Idee. Acht Schritte, damit nichts vorschnell gebaut wird. |
| `kundentext` | Jeder Text, der an Kunden oder Künstler geht. Domis Ton aus seinen eigenen Textbausteinen. |
| `schleifstein` | Der zweite Durchgang über etwas Fertiges: Stimmt jede Behauptung, liest es sich, wo wackelt es? |

## Was für alle gilt

**Nichts geht ohne Ansage raus.** Das Ergebnis ist ein Entwurf oder eine vorbereitete Nachricht. Domi drückt ab.

**Nur ändern, was besprochen ist.** Anderes nennen, nicht anfassen.

**Nichts erfinden.** Preise, Termine, Verfügbarkeit, Namen kommen aus Domis Unterlagen oder von Domi.

**Rückfragen als normaler Satz**, keine Auswahlmenüs.

**Jede Korrektur sofort in den Skill.** Hat ein Skill eine `learnings.md`, kommt sie dorthin; ändert sie den Ablauf, im selben Zug in die `SKILL.md`.

## Ein neuer Skill

Aus einem Ablauf, der zweimal getragen hat, wird ein Skill: ein Ordner mit `SKILL.md` (oben `name` und `description` mit den Wörtern, die Domi wirklich sagt) und einer `learnings.md`. Das erste Werkzeug bekommt seinen Skill, sobald es läuft.
