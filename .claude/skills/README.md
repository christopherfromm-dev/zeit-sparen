# Skills im Projekt «Zeit sparen»

Angelegt am 22.11.2026 nach dem Muster von SHV und Kunstprojekt. Aufrufen mit
`/name`. Wie ein neuer Skill entsteht: `vorlagen/skills-aufbau.md`.

| Skill | Wofür |
|---|---|
| `morgen` | Beim Start: GitHub abgleichen, Stand, Domi, Drive-Ordner, ein erster Schritt, eine Frage. Hook erkennt Grusswort oder acht Stunden Pause. |
| `lernen` | Am Ende jedes Chats und nach jeder Korrektur: Learnings ablegen, committen und pushen, Stand nachführen. Hook erinnert bei «merken» und «gute Nacht». |
| `anfangen` | Die Leitlinie für jeden Anfang: neuer Kunde, neues Werkzeug, neuer Skill. |

## Was für alle gilt

**Nichts geht ohne Ansage raus.** Keine Mail, kein WhatsApp, keine Rechnung,
keine Nachricht an Domi oder einen Kunden. Das Ergebnis ist ein Entwurf, den
Chris sieht.

**Kundendaten bleiben beim Kunden.** Keine Nummern, Buchungen, Passwörter ins
Repository.

**Getrennt von streckenfliegen.** Nichts von hier dorthin, nichts von dort hierher.

**Nur ändern, was besprochen ist.** Fällt beim Arbeiten etwas anderes auf:
nennen, nicht anfassen.

**Rückfragen als Fliesstext**, keine Auswahldialoge.
