# <Titel> · Learnings

Ein Eintrag pro Auftrag, neueste unten. Hier steht, was passiert ist und was <Kunde> gesagt hat. Was davon zum festen Ablauf wird, steht in [SKILL.md](SKILL.md). Ändert ein Eintrag den Ablauf, wird SKILL.md im selben Zug angepasst und hier vermerkt («→ Skill, Schritt N»).

**Vorlage für einen neuen Eintrag:**

```
## TT.MM.JJJJ · Auftrag in drei Wörtern
**Anlass:** woher, sein Auftrag wörtlich
**Was getragen hat:** …
**Seine Korrekturen:** «Zitat» (Datum) und was daraus wurde
**Fehler von mir:** …
**Minuten:** vorher … / nachher …
**→ Skill:** was in SKILL.md geändert wurde, oder «nichts Neues»
```
