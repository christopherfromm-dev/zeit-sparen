# Zeit sparen

Gemeinsames Projekt von Chris und Domi. Eigenes Repository, getrennt von streckenfliegen.com.

Wir verkaufen Zeit: Abläufe eines Kunden ansehen, das Problem finden, das am meisten Zeit kostet, ein Werkzeug dafür bauen.

## Aufbau

| Ordner | Inhalt |
| :- | :- |
| `kunden/` | ein Ordner pro Fall: Vorbereitung, Befund, Einrichtung, Messung |
| `kunden/domi-agentur/` | Fall 0: Domis Agentur (Termin 22./23.11.2026) |
| `vorlagen/` | wiederverwendbare Vorlagen: Heute-Liste, Posteingang, Sicherung, Skills (aus Chris' Büro), später Erstgespräch und Protokoll |
| `werkzeuge/` | gebaute Werkzeuge (Skills, Skripte), die mehrere Kunden nutzen können |
| `protokolle/` | Gespräche und Nachschauen |

## Wo was liegt

- Dieses Repository: Anleitungen, Vorlagen, Werkzeuge.
- Google Drive «Zeit sparen – Chris & Domi»: Zusammenfassung, Checkliste Erstgespräch, Tabelle «To-dos, Kunden und Use Cases», Protokolle zum Lesen.
- Kundendaten (Buchungen, Nummern, Passwörter) gehören **nicht** hier hinein. Sie bleiben beim Kunden.
